Hg-Ne Lamp

The Hg-Ne Lamp provides the light that will eject electrons from the metal. Mercury is an ideal light source for this purpose because it emits a lot of light, but only in a small number of wavelengths.

Use tool

Click to toggle the lamp!

Potentiometer

The voltage is adjusted by turning the knob of a variable resistor (also known as a potentiometer).

Use tool

Choose an option to set the amount of rotation per click. Click an arrow to rotate the knob in that direction.
